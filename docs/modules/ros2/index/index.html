ROS 2 Fundamentals

Welcome to the ROS 2 module of the Physical AI & Humanoid Robotics course. This module provides a comprehensive introduction to ROS 2 (Robot Operating System 2), the middleware framework that enables communication between different software components in robotic systems.

Learning Objectives#

By the end of this module, you will be able to:

  • Understand ROS 2 architecture and core concepts
  • Create and manage ROS 2 nodes with Python
  • Implement publisher-subscriber communication
  • Design and implement service-based communication
  • Build ROS 2 packages with proper structure
  • Configure and use launch files for complex systems
  • Manage parameters and coordinate frames for humanoid robots

Topics Covered#

  • ROS 2 Fundamentals
  • Nodes, Topics and Services
  • URDF for Humanoids

Prerequisites#

  • Basic Python programming knowledge
  • Understanding of Physical AI concepts
  • Familiarity with Linux command line
  • Basic understanding of robotics concepts
